# memory/domain.md — Словарь предметной области и бизнес-правила

## 1. Сущности и понятия

### Пользователь (User)
- **Telegram ID (`telegram_id`):** Уникальный числовой идентификатор пользователя в Telegram (хранится как `BIGINT`).
- **Бесплатные запросы (`free_requests_left`):** Стартовый баланс (по умолчанию 5 сообщений), позволяющий новому пользователю протестировать бота до оформления подписки.
- **Премиум-статус (`is_premium`):** Флаг активной платной подписки. Пока `is_premium = true` и текущее время < `premium_until`, пользователь имеет безлимитный или расширенный доступ.
- **Заморозка подписки (`frozen_premium_seconds`):** Механизм приостановки действия подписки (сохраняет оставшиеся секунды тарифа на балансе).

### Память и контекст (Memory & Context)
- **Typed Memory (Типизированная память):** Структурированные факты о пользователе (имя, город, увлечения, предпочтения, триггеры), извлеченные из диалога через `src/ai/memory_extractor.js`.
- **Outbox Worker:** Очередь асинхронной обработки и сохранения фактов, чтобы не замедлять генерацию ответа пользователю.
- **Semantica Memory:** Векторные эмбеддинги и семантический поиск релевантных воспоминаний под текущий вопрос.

### Radiant NPC (Личность и симуляция)
- **Персонаж (Лера):** Студентка 2 курса СПбГИК, 19 лет, подрабатывает в SMM, живет в Санкт-Петербурге.
- **Потребности (Needs):** Энергия (`energy`), голод (`hunger`), социальность (`social`). Значения динамически падают со временем и восстанавливаются действиями.
- **Суточный цикл (Routine):** Расписание дня (сон, пары в универе, работа над SMM-проектами, прогулки по Питеру, отдых).
- **Инициатива (Initiative):** Способность персонажа написать пользователю первой или предложить тему для обсуждения, исходя из суточного контекста и уровня взаимоотношений.

### Контент и каналы (Channel Management)
- **Channel Poster:** Автоматический планировщик публикаций в подключенный Telegram-канал.
- **Discussion Outbox:** Очередь автоматических комментариев персонажа под свежими постами канала для создания живой активности.

### Платежи и тарифы (Payments)
- **Инвойс (Invoice):** Ссылка и ID счета в системе Platega на фиксированную сумму в RUB.
- **Тарифный план:** Период продления премиума (например, 30 дней, 90 дней, 365 дней).
- **Реферал / Реферер:** Приглашенный пользователь и автор приглашения (`referred_by`).

## 2. Бизнес-правила

1. **Правило списания запроса:**
   - Если `is_premium = true` и подписка не истекла -> запрос разрешен без списания `free_requests_left`.
   - Если `is_premium = false` и `free_requests_left > 0` -> запрос разрешен, `free_requests_left` уменьшается на 1.
   - Если `free_requests_left <= 0` -> бот отправляет предложение оформить подписку с кнопками тарифов.
2. **Правило активации платежа:**
   - При успешном вебхуке Platega, если у пользователя уже был активен премиум, новый период прибавляется к существующей дате `premium_until`.
3. **Правило тональности ответов:**
   - Ответы всегда генерируются в соответствии с характером Леры (естественный сленг, краткость, теплый сарказм, без роботизированных фраз и шаблонных дисклеймеров).
