# memory/frontend.md — Веб-админка (admin-v2)

## 1. Стек и технологии

- **Фреймворк:** React 19 (`admin-v2/src/App.jsx`, `main.jsx`)
- **Сборщик:** Vite (`admin-v2/vite.config.js`)
- **Стилизация:** Tailwind CSS v4 (`@tailwindcss/vite`), кастомная дизайн-система (`design-system.css`, `feature-components.css`)
- **UI-примитивы:** Radix UI (`@radix-ui/react-dialog`, `@radix-ui/react-tabs`, `@radix-ui/react-alert-dialog`), Base UI (`@base-ui/react`)
- **Иконки:** `lucide-react`
- **Команда сборки:** `npm run admin:build`

---

## 2. Структура `admin-v2/`

```
admin-v2/
├── index.html              # HTML шаблон приложения
├── vite.config.js          # Конфигурация Vite для admin-v2
├── components.json         # Конфигурация компонентов shadcn/ui
└── src/
    ├── App.jsx             # Корневой лейаут и роутер вкладок
    ├── main.jsx            # Точка входа React приложения
    ├── index.css           # Базовые стили и подключение шрифтов
    ├── design-system.css   # Переменные цветов, отступов, радиусов, токенов
    ├── feature-components.css # Стили для специфичных компонентов модулей
    ├── components/         # Переиспользуемые UI-компоненты (кнопки, диалоги, инпуты)
    ├── lib/                # Утилиты (clsx, twMerge, api клиент)
    └── features/           # Модули админ-панели:
        ├── crm/            # Список пользователей, история сообщений, балансы
        ├── channel/        # Управление каналом, планировщик постов
        ├── content/        # Контент-план, шаблоны тем, генератор постов
        ├── providers/      # Матрица моделей AI, балансы токенов, провайдеры
        ├── simulation/     # Radiant монитор: шкалы потребностей, погода, локация
        └── studio/         # Prompt Studio: песочница тестирования промптов
```

---

## 3. Модули и их назначение

| Модуль | Описание |
|---|---|
| **CRM (`features/crm`)** | Просмотр пользователей бота, их статус подписки (`is_premium`), остаток бесплатных запросов, история оплат и лог сообщений. |
| **Channel (`features/channel`)** | Мониторинг Telegram-канала, статус отложенных постов, статистика комментариев, запуск автопостинга. |
| **Content (`features/content`)** | Генерация постов с медиа, предпросмотр контента, управление топиками и стилями постов. |
| **Providers (`features/providers`)** | Конфигурация моделей AI Matrix (OpenRouter, Gemini, OpenAI), установка фолбэков и лимитов. |
| **Simulation (`features/simulation`)** | Интерактивный дашборд состояния Radiant NPC: шкала энергии, голода, текущая локация по карте, погода в СПб, ручные триггеры действий. |
| **Studio (`features/studio`)** | Отладка системного промпта, живой чат-песочница с ботом, проверка качества ответов (`response_judge`). |

---

## 4. Правила разработки UI

1. **Дизайн-система:** Используй существующие токены из `design-system.css`. Не хардкодь случайные hex-цвета, если есть семантические переменные.
2. **Адаптивность и состояния:** Все кнопки и формы должны иметь явные состояния `hover`, `focus-visible`, `disabled` и `loading`.
3. **Проверка сборки:** Любые правки во фронтенде обязательно валидируются командой `npm run admin:build`.
