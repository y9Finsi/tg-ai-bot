# memory/frontend.md — Веб-админка (admin-linear)

## 1. Стек и технологии

- **Фреймворк:** React 19 (`admin-linear/src/App.jsx`, `main.jsx`)
- **Сборщик:** Vite (`admin-linear/vite.config.js`)
- **Стилизация:** Tailwind CSS v4 (`@tailwindcss/vite`), Linear Design System (Inter Variable, `#08090a` canvas, `#0e1013` surfaces, `#5e6ad2` accent)
- **Иконки:** `lucide-react` (строго нормализованы к `stroke-[1.5]`)
- **Интерактивные карты:** Leaflet (OpenStreetMap с кастомным темным инвертированным стилем `.osm-dark-tiles`)
- **Паттерны:** `better-ui` (концентрические радиусы, scale on press 0.96, явные transition-свойства, WCAG AA контраст) и `better-layout` (группировка пространством, full bleed карта, плавающий HUD с safe-area)
- **Команда сборки:** `npm run admin:build` (собирает в `public/admin-linear`)

### Вкладка 3: «Карта СПб» — Интерактивная Zenly-карта (ZenlyMap)
- **Стиль Zenly:** пухлые круглые аватары персонажей с пульсирующим радар-кольцом, динамический % заряда батареи с цветовой кодировкой, статус-пилюли с активностью и скоростью, метка времени на месте («Здесь 35м»).
- **Двухдвижковая архитектура (Dual Engine):**
  - *Основной:* Яндекс Карты JS API 3.0 (`ymaps3`) с вектором, адаптивной темой и 3D зданиями с наклоном 42° (`tilt: (42 * Math.PI) / 180`).
  - *Graceful Fallback:* MapLibre GL с Carto Voyager (день) / Carto Dark Matter (ночь) и 3D extrusions на случай сетевых ограничений или отсутствия referer.
  - *Ручной переключатель:* кликабельный бейдж в верхнем HUD («Яндекс 3D» ⇄ «MapLibre 3D») и переключатель световых тем (☀️ День / 🌅 Закат / 🌙 Ночь / ⚡ Авто по `calculateSpbSun()`).
- **Честный транзит (Transit Engine):**
  - Клик по точке назначения не телепортирует Леру мгновенно, а открывает карточку маршрута с расчетом дистанции (км), времени пешком и цены такси.
  - При выборе пути («🚶‍♀️ Идти» или «🚕 Заказать такси») отправляется `taskType: 'TRAVEL'` в Radiant симуляцию.
  - На карте строится неоновая пунктирная линия пути (`route-path-source`, GeoJSON LineString).
  - Прогресс транзита (0% → 100%) честно тикает в симуляции (+15 мин), статус переходит в `IN_TRANSIT`, и персонаж перемещается только по прибытии.
- **Стабильная фиксация 14 меток СПб:**
  - База из 14 проверенных локаций СПб (Дом на Петроградке, СПбГИК, Севкабель, Новая Голландия, кофейня Слой, Сенная, Рубинштейна и др.).
  - Строгая фиксация маркеров (`anchor: 'bottom'`) без конфликтующих `transform: translate`, метки жестко закреплены на фасадах при любом наклоне и зуме.
  - Модальный каталог `ZenlyPlacesCatalogModal` с поиском, категориями и дистанциями от Леры.
- **Очистка от оверинжиниринга и контекстные действия:**
  - Полностью удален визуальный шум: фейковые фонтанчики эмодзи-реакций и неработающая кнопка «Написать в TG».
  - В локациях добавлены честные контекстные действия (купить кофе/круассан, смена в шоуруме, учеба в СПбГИК, сон/душ дома), мутирующие потребности Леры.

## 4. Правила разработки UI (`better-ui` & `better-layout`)

1. **Концентрический радиус скругления:** `outerRadius = innerRadius + padding` (доки `rounded-3xl` при `p-3` и child `rounded-xl`; колонки `rounded-2xl` при `p-2.5` и child `rounded-md`).
2. **Тактильный отклик (Scale on Press):** `active:scale-[0.96]` со специфичным `transition-[...,transform] duration-150` на всех кнопках.
3. **Запрет `transition: all`:** объявлять только целевые анимируемые свойства (`transition-colors`, `transition-[background-color,border-color,color,transform]`).
4. **Иконки:** везде `stroke-[1.5]` для визуального баланса со шрифтом Inter Variable.
5. **Группировка пространством:** минимум внутренних разделительных линий; разделение за счет отступов (gap).
6. **Контрастность:** микро-текст строго `text-white/50` или выше (WCAG AA).
7. **Хоткеи:**
   - `T` — шаг +15 мин
   - `Space` — пауза / старт
   - `R` — обновить данные
   - `M` — быстро переключить вкладку (Пульт ↔ Карта)

## 5. 3D Симулятор Петроградки (MapLibre GL + Three.js)

1. **Архитектура WebGL и глубина:**
   - MapLibre GL с `renderingMode: '3d'` шарит WebGL depth buffer с Three.js (`renderer.autoClear = false`).
   - Координатная сетка привязана к центру Петроградки `[30.3080, 59.9590]` через матрицу Меркатора (1 unit = 1 meter).
2. **Фасады и крыши (Milestone M1):**
   - Процедурный атлас классицистических фасадов Петербурга (`pixelRatio: 32`): рустованный гранитный цоколь, классические окна с наличниками и подоконниками, арочные парадные порталы.
   - Слой фальцевых графитовых крыш `3d-buildings-roof` (+0.12m над зданиями) полностью исключает наложение окон на крыши.
   - Белая разметка пешеходных переходов (зебры) и прерывистые осевые линии на проспектах.
3. **GTA 3D персонажи и NavMesh (Milestone M2):**
   - 12-составная biped-иерархия с синусоидальной биомеханической кинематикой шага.
   - Вращающийся изумрудный Sims Plumbob над Лерой.
   - 4-уровневый NavMesh с физической проверкой коллизий по 1080 зданиям Петроградки — 0.000% коллизий с домами.
   - Физические 3D магазины и кафе с ночными PointLight источниками («Слой», «ВкусВилл», «Шоурум»).
   - Поддержка открытых 3D моделей GLB (`michelle.glb`, `lera.glb`, `citizen.glb`) с процедурным fallback.
4. **Городская среда и трафик (Milestone M3):**
   - Деревья строго внутри парковых полигонов (Матвеевский сад, сквер Низами) и в тротуарных лунках Большого проспекта с контролем минимальной дистанции Пуассона — 0 деревьев на крышах и во дворах.
   - Чугунные фонари освещения и дорожная разметка строго по поребрикам и полосам движения проспектов — 0 фонарей и переходов на газонах парков.
   - Автомобильный трафик (такси, седаны, лазурный автобус СПб) по точным дорожным сплайнам Большого и Каменноостровского с физикой Intelligent Driver Model (IDM) и объемными световыми лучами фар.
   - Астрономический калькулятор солнца СПб (`solarCalculator.js`): автоматический расчет угла высоты, азимута и длины теней в реальном времени.
   - Сбалансированное озеленение Петроградской стороны (`cityEnvironmentData.js`): Матвеевский сад (35 деревьев), сквер Низами (40 деревьев), Александровский парк (95 деревьев) и аллеи Большого и Каменноостровского проспектов (`PETROGRADKA_TREES`).

5. **Пешеходная навигация и Follow Cam (`pedestrianData.js`, `FullScreenMap.jsx`):**
    - Единая 100% связная топология тротуаров через Каменноостровский проспект и узел дома Леры без коллизий со зданиями.
    - Поиск кратчайшего пути по тротуарам `findNavMeshPath` и транзит `createLeraTransit` / `interpolateTransitPosition`.
    - Плавный цикл ходьбы (biped gait), синхронизированный бабл цели над головой («Иду в «Слой» ☕», «Бегу в СПбГИК 🎓»).
    - Режим следящей камеры від 3-го лица (Follow Cam) с автоотключением при ручном перетаскивании карты.

6. **Полноценная 3D Комната Леры (`admin-linear/src/lib/threeRoom/`, `ApartmentInteriorModal.jsx`):**
