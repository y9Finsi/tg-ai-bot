# memory/index.md — Навигационный индекс памяти

Этот файл объясняет назначение каждого слоя памяти проекта `tg-ai-bot`. Читай только те файлы, которые относятся к твоей текущей задаче.

---

## Карта слоев памяти

### 1. [architecture.md](file:///Users/bogdan/Desktop/Telegram-AI-bot-with-payments-main/memory/architecture.md) — Общая архитектура
- **Когда читать:** проектирование новых фич, добавление сервисов, изменение топологии Docker/микросервисов, понимание общих связей между ботом, сервером, БД, очередями и Semantica.
- **Содержит:** диаграмму взаимодействия, список портов и сервисов, потоки данных от Telegram апдейта до генерации ответа.

### 2. [backend.md](file:///Users/bogdan/Desktop/Telegram-AI-bot-with-payments-main/memory/backend.md) — Бэкенд и логика
- **Когда читать:** работа с кодом в `src/`, изменения Telegram бота (`bot.js`), API роутов (`server.js`), репозиториев БД (`src/db/`), BullMQ очередей (`queue.js`), AI Matrix и движка NPC Radiant (`src/radiant/`).
- **Содержит:** карту каталогов `src/`, таблицы БД и миграции, логику симуляции персонажа, контекстный пайплайн LLM.

### 3. [frontend.md](file:///Users/bogdan/Desktop/Telegram-AI-bot-with-payments-main/memory/frontend.md) — Веб-админка (admin-v2)
- **Когда читать:** верстка, добавление табов и экранов в админку, стилизация, UI-компоненты, интеграция с API сервера.
- **Содержит:** стек React 19 + Tailwind v4 + Radix, структуру `admin-v2/src/features`, правила оформления стилей и дизайн-систему.

### 4. [payments.md](file:///Users/bogdan/Desktop/Telegram-AI-bot-with-payments-main/memory/payments.md) — Платежная система
- **Когда читать:** работа с тарифами, пополнением баланса, подписками, интеграцией Platega, обработкой вебхуков оплаты и реферальной системой.
- **Содержит:** флоу создания и проверки счетов, обработку вебхука `/webhook/platega`, заморозку премиума, тарифные константы.

### 5. [gotchas.md](file:///Users/bogdan/Desktop/Telegram-AI-bot-with-payments-main/memory/gotchas.md) — Подводные камни и грабли
- **Когда читать:** отладка сложных багов, таймаутов, падений, перед рефакторингом критических узлов (concurrency, graceful shutdown, Telegram rate limits).
- **Содержит:** список известных неочевидных ограничений, тонкие места очередей, особенности fallback-логики AI.

### 6. [domain.md](file:///Users/bogdan/Desktop/Telegram-AI-bot-with-payments-main/memory/domain.md) — Словарь предметной области
- **Когда читать:** при добавлении бизнес-логики, чтобы не гадать, что значат термины и как работают правила продукта.
- **Содержит:** определения сущностей (User, Premium, Initiative, Routine, Token, Invoice), жизненный цикл сущностей.

## Правило работы с памятью
1. **Ленивая загрузка:** бери только нужный файл под задачу.
2. **Точечная актуализация:** изменил логику/роут/таблицу — обнови соответствующий md-файл.
